Before you start

What You Are Going To Set Up

The mess manager will run on Vercel - a professional hosting service used by thousands of companies. Your records will live in a Neon cloud database. Both have permanent free plans. Nothing in the app needs to be changed or coded - the SQLite to Postgres switch and the table creation happen automatically during the first build. You only click buttons and copy-paste one address.

You need

An internet connection, 20–25 quiet minutes, and one email address. All three accounts (GitHub, Neon, Vercel) are free and card is never asked.

The order of work

Step 1 · GitHub = your files on the internet. Step 2 · Neon = your database. Step 3 · Vercel = puts both together and gives you the URL. Follow the steps in order, do not skip.

Step 1

GitHub - Put the Files Online

  1. Go to github.com and click Sign up. Enter your email, make a password, and type the verification code they email you.
  2. While logged in, open github.com/new.
  3. Repository name: type zubair-hall-mess. Select Private. Click Create repository.
  4. On the new empty page, click the link “uploading an existing file”.
  5. Open your extracted app folder on the PC. Press Ctrl+A to select everything, then drag the selection onto the GitHub page and wait until every file is listed.
  6. Click Commit changes. The upload of a few hundred small files takes a few minutes - let it finish.

Step 2

Neon - Free Database

  1. Go to neon.tech and click Sign Up. Continue with Google is the fastest.
  2. Create a new project. Name it zubair-hall-mess. Any region is fine. Click Create.
  3. Neon shows a connection string - a long line starting with postgresql://. Click the Copy icon next to it.
  4. Paste it in Notepad and save. This long line is the address AND the key of your database.

Keep it private

Anyone who has this string can read your mess data. Never post it in a group chat. (It ends with something like sslmode=require - keep the full line exactly as copied.)

Step 3

Vercel - Your Own URL

  1. Go to vercel.com and click Sign Up → Continue with GitHub (the same account you just made).
  2. Click Add New… → Project, then click Import next to zubair-hall-mess.
  3. Project Name: keep it exactly zubair-hall-mess - your app URL becomes https://zubair-hall-mess.vercel.app. If the name is already taken, use zubairhall-mess or add -2; the URL always matches the name you type.
  4. Open the Environment Variables section and add two rows:
    • Name DATABASE_URL → Value: paste the long postgresql://… string from Neon.
    • Name SESSION_SECRET → Value: mash your keyboard for one long random line of letters and numbers, and end it with something private only you know.
  5. Click Deploy and wait 3–5 minutes for the confetti screen.

No code changes needed

During this first build the app switches itself to Postgres and creates all database tables automatically. You never open a terminal.

Step 4

First Login and Safety

  1. Open your URL - https://zubair-hall-mess.vercel.app (Vercel also shows it under Domains). It opens from any phone, anywhere.
  2. Log in with the initial password Hadi2750.
  3. Immediately go to Settings → Change password. The app is now on the internet, so a private password is your lock.
  4. To try the features, press Load 10-day sample data on the dashboard. Before starting real records, remove the demo: Settings → Data → Clear all data (type DELETE to confirm).
  5. Every week: Settings → Data → Download full backup and keep the file somewhere safe (WhatsApp saved messages, Google Drive, USB).
Problems?

Common Issues and Fixes

What you seeWhat to do
“The repository name already exists” on VercelAnother person in the world took that exact name. Use zubair-hall-mess-2 or zubairhall-mess - the URL follows the name.
Deploy failedOpen the failing deployment → Build Logs. 9 out of 10 times the DATABASE_URL variable is missing, misspelled, or not the complete string. Re-check Settings → Environment Variables and press Redeploy.
App opens but login shows an errorTake a screenshot of the Vercel Build Logs and ask for help - the fix is usually one variable.
Password forgotten (cloud)Open neon.tech → your project → SQL Editor → type DELETE FROM "Credential"; and press Run. Log in again with Hadi2750 and change it at once.
You received an improved version laterUpload the new files to the same GitHub repository (drag & drop, replace). Vercel redeploys automatically; your data stays safe in Neon.
